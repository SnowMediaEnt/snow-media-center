# Snow Media game server

Source snapshot of the existing VPS game server, with validated Dice and Trivia
sessions added. Runtime is Node 20+ at `/opt/smc-game-server`; secrets remain in
the VPS `.env` and are never part of this directory.

Dice rolls are generated by `crypto.randomInt`. Clients send held positions and
bank intents. Trivia challenges use the published Supabase bank plus the reviewed
bundled fallback; only the current prompt and shuffled choices are sent before an
answer. The server grades each answer and computes the final score and payout.

`arcade_sessions` is private to the service role. A start reserves the wager once;
versioned actions and atomic settlement make retries safe. Results, the coin
ledger, and score records commit together. Sessions resume for up to 24 hours.
The public question catalogue no longer distributes grading keys.

Validation: `npm ci && npm test` in this directory. Tests do not use real balances
or credentials. Regenerate `triviaBank.json` from the root with
`node scripts/games/export-trivia-bank.mjs` when curated fallback content changes.

Deployment order: apply the verified-arcade SQL migration, deploy the catalogue
function, then copy `src/games/{arcade,verifiedArcade}.js`, `triviaBank.json`, and
`src/server.js` to the VPS and restart its existing PM2 process. Other game source
files are retained here for reproducible tests, and are not overwritten on this
release. Publish the connected web client and rebuild the Android APK for devices
that bundle the client. Older APKs receive `game_update_required` when attempting
unverified Dice/Trivia coin settlement.
